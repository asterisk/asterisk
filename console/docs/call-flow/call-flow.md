# Call Flow

## Behavior

Call Flow provides a visual and keyboard-operable composition of routes, menus, queues, groups, conditions, and fallbacks. The graph always has an equivalent structured outline for screen readers and export.

## Configuration

Nodes come from verified destination registries. Connections, labels, priorities, entry points, and fallbacks are editable through guided pickers; blank canvases offer presets derived from real defaults.

## Failure modes and security

Cycle, orphan, unreachable node, missing permission, conflicting entry, incomplete configuration, and publication refusal remain visible. Simulation is local and does not place a call.

## Verification

Test pointer and keyboard creation, graph/outline equivalence, cycle detection, every preset, export/import, simulator fixtures, publication readback, rollback, and large-graph performance.
