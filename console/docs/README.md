# Ding PBX Console documentation

Ding PBX Console is a planned Windows desktop administration experience for Asterisk. This documentation website is a landing, documentation, download, status, settings, and link surface only. It is not the installed desktop application and it is not a PBX runtime.

The documentation map contains 32 destinations in six categories. Every article covers behavior, configuration, failure modes, security, verification, and suggested reading.

## Categories

- [Overview](overview/README.md) — dashboard, live calls, health, status, reports, records, logs, and documentation.
- [People and devices](people-devices/README.md) — users, devices, contacts, and voicemail.
- [Connectivity](connectivity/README.md) — trunks and extensions.
- [Call flow](call-flow/README.md) — routes, interactive voice response, visual call flow, and time conditions.
- [Team calling](team-calling/README.md) — queues, ring groups, conferences, paging, announcements, recordings, and security.
- [Manage](manage/README.md) — backups, updates, automation and conversion, local AI, appearance, accessibility, and settings.

## Shared site behavior

The website stores visitor choices only in browser storage. It makes no analytics request, loads no runtime CDN asset, and does not contact Asterisk or Ollama. Uploaded logo and vocabulary files are validated and previewed locally; exports omit uploaded vocabulary, ticket descriptions, and lock credentials. Clearing browser data resets all site-local state.

The installer control remains unavailable until a verified, immutable release manifest provides an exact release asset URL. The Open Graph image path is reserved for a future committed product capture; metadata must not be treated as proof that the image has shipped.
