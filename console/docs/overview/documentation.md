# Documentation

## Behavior

Documentation provides an article for every destination and shared capability, with categorized navigation, search, suggested reading, and honest product boundaries. The installed application will bundle the same articles for offline use.

## Configuration

Language, text size, theme, tab docking, pinning, grouping, and local attention accommodations apply without changing technical facts. Search uses literal text by default and a bounded JavaScript regular-expression mode by choice.

## Failure modes and security

A missing article, broken internal link, stale version, unavailable capture, or unsupported feature remains visible and blocks a completeness claim. Provider-authored text must pass through one isolated renderer; this static source contains no remote scripts.

## Verification

Check all 32 article paths, headings, internal links, narrow layout, keyboard navigation, both themes, language modes, search, and built output. A completeness test must fail when an enumerated article is removed.
