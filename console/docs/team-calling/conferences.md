# Conferences

## Behavior

Conferences manage rooms, participants, moderators, entry and exit prompts, mute state, capacity, recording policy, and observed activity. Joining a room is never simulated as success.

## Configuration

Guided controls select room number, role policy, access method, capacity, prompts, language, recording, and end conditions. Existing rooms and available recordings populate pickers.

## Failure modes and security

Capacity reached, duplicate room, invalid access, unavailable media, recording refusal, and stale participant state remain separate. Access credentials stay in the operating-system vault and are never displayed or exported.

## Verification

Exercise moderator and participant joins, capacity, mute, removal, prompt failures, recording consent, room end, permissions, keyboard actions, and independent bridge-state readback.
