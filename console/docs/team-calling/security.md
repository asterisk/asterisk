# Security

## Behavior

Security brings transport, certificate, account, credential, access-rule, audit, rate-limit, and exposure findings into one role-protected destination. It describes evidence and recovery rather than promising perfect protection.

## Configuration

Users configure allowlisted networks, transport requirements, account roles, session policy, audit retention, alert thresholds, and credential rotation through guided controls. Secret entry occurs only through protected system surfaces.

## Failure modes and security

Invalid rule, lockout risk, expired certificate, weak transport, refused vault, stale audit source, and partial application remain explicit. A safety-reducing change requires exact impact review and destructive-action confirmation where irreversible.

## Verification

Test role boundaries, lockout prevention, transport and certificate states, rate limiting, redaction, audit completeness, failed vault access, rollback, keyboard operation, and independent configuration readback.
