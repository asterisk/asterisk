# Accessibility

## Behavior

Accessibility covers keyboard operation, visible focus, semantic roles and names, screen-reader announcements, contrast, reduced motion, text scaling, touch targets, language modes, and non-colour status throughout every destination.

## Configuration

Users can choose theme, text scale, density, reduced stimulation, narrator preferences in the installed application, and independent attention accommodations. Operating-system reduced-motion preference is honored without another opt-in.

## Failure modes and security

Missing label, focus trap, clipped content, colour-only state, motion that ignores preference, unreachable control, or ambiguous error is a release-blocking defect. Accessibility settings never weaken security facts or hide affected data.

## Verification

Run keyboard-only journeys, screen-reader name/state checks, focus-order review, contrast checks, reduced-motion inspection, 320-pixel and tablet widths, touch operation, 100–200% scale, longest bilingual strings, and every overlay edge.
