# Appearance

## Behavior

Appearance controls theme, density, accent, installed fonts, scale, element presentation, app display name, and local logo. Changes apply immediately where possible, persist, export without private uploads, and reset by property or globally.

## Configuration

Every element exposes an appearance command and keyboard equivalent. Colour uses a continuous picker plus accessible contrast and translated representations. Logo presets and bounded local image upload offer fit, crop-equivalent positioning, background, and target previews without changing package identity.

## Failure modes and security

Unsupported property, missing font, invalid colour, malformed image, spoofed type, oversized decode, conversion failure, and corrupt cache retain the prior valid presentation. Custom images stay local and out of history, export, captures, and network requests.

## Verification

Test presets, custom upload, byte/type mismatch, size bounds, fit/background, persistence, reset, cache corruption, theme contrast, font fallback, narrow/high-scale layout, keyboard control, and packaged rendering.
