# Local AI

## Behavior

Local AI documents an independent Ollama suite manager using only Ollama's documented loopback HTTP API. The installed application will show runtime health, an exhaustive model and variant store, evidence-backed hardware fit, bounded batch pulls, local chat, and allowlisted harness profiles. This website makes no Ollama request.

## Configuration

Real-data pickers cover model, variant, quantization, context, parameters, destination, and registered harness profile. Hardware fit is Runs well, Runs with limits, Unlikely, or Unknown and cites RAM, GPU, VRAM, driver, storage, blob size, parameters, quantization, and context assumptions.

## Failure modes and security

Missing runtime, stopped service, malformed response, stale catalogue, insufficient storage, unknown fit, pull failure, unsupported attachment, and harness rollback are distinct. Profiles allowlist executables and arguments; secrets stay in the operating-system vault.

## Verification

Test exhaustive pagination, offline cache, fit evidence, bounded pull progress, cancel/retry/resume, streamed chat, capability-gated attachments, snapshot/restore, failed-launch rollback, malformed responses, and no arbitrary shell path.
