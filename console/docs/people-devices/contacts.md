# Contacts

## Behavior

Contacts combines permitted shared and personal directory entries with source, owner, numbers, labels, and synchronization state. Duplicate candidates are shown for review rather than merged automatically.

## Configuration

Users can import supported structured formats, map fields, choose conflict policy, group entries, and apply previewed bulk tag, move, copy, export, and delete actions.

## Failure modes and security

Malformed imports, duplicate fields, unsupported encoding, permission refusal, stale source, and partial synchronization remain explicit. Private entries follow role and owner boundaries; exports name omitted fields.

## Verification

Test import mapping, Unicode, deduplication, every bulk-selection scope, partial results, round-trip exports, local search bounds, keyboard actions, and access controls.
