# Devices

## Behavior

Devices describe phones and endpoints, their assigned user, provisioning state, network reachability, transport, codec support, and last contact. Discovery never silently enrolls a device.

## Configuration

Guided forms provide detected models, supported templates, available users, extension choices, transport, and validated network settings. Advanced fields remain available with documented defaults.

## Failure modes and security

Unsupported model, unreachable device, provisioning refusal, stale registration, certificate problem, and partial update are distinct. Provisioning credentials remain outside renderer state and diagnostic exports.

## Verification

Exercise detected and manual devices, template validation, reachability transitions, credential refusal, rollback, keyboard browse controls, high-scale layout, and readback from the authoritative device source.
